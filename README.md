# Professional Website

A static academic and professional portfolio, designed for GitHub Pages.

## Deploy

1. Upload the contents of this folder (not the enclosing folder) to the `main` branch of `SteinXI/Professional-Website`. `index.html` must be in the repository root.
2. Under **Settings → Pages**, select **Deploy from a branch**, then `main` and `/(root)`.
3. Open `https://steinxi.github.io/Professional-Website/` after GitHub Pages completes deployment.

## Structure

- `index.html` — homepage with fixed middle-left floating navigation on desktop
- `assets/style.css` — responsive colours, typography, layouts and navigation
- `assets/site.js` — active-section navigation and mobile menu
- `about.html`, `research.html`, `experience.html`, `education.html`, `projects.html`, `credentials.html` — starter detail pages

## Notes

Content explicitly labelled as a placeholder requires review before public launch. All URLs are relative for GitHub Pages project-site compatibility. No build tools or paid services are required.
